# 目标一详解：搜到"搜不到"的法律与信息

> 核心信念：**"搜不到"几乎总是方法不对，不是信息不存在。** 本文件是把这句话落地的完整方法论。

## 一、大数据检索思维（打通多源数据）

大数据的核心不在"数据量大"，而在**把不同渠道、互不相连的数据打通**。一个来源匿名/残缺的信息，往往能被另一个来源补全。

### 经典实战：律所出纳私吞 4426 万案——如何锁定被匿名的律所
1. **已知线索**：新闻报道——某律所北京代表处出纳私吞 4426 万，购千万房产、送玛莎拉蒂，被北京三中院判 14 年（郭某）。
2. **AI 只指路**：先问 AI/搜索找方向，AI 提示"可查裁判文书确认"，但不能直接采信 AI 给的律所名。
3. **专业库/文书检索**：用最具辨识度的关键词 `玛莎拉蒂 + 北京三中院` 检索 → 命中一审二审文书，金额 4426 万高度一致、法院/姓氏/时间都对得上 → 确认是本案。
4. **卡点**：文书把律所名匿名为"××"。多数人到此放弃。
5. **不抛弃不放弃**：继续往下翻文书 → 证人吴某证言透露"2012 年任某律所北京代表处首席代表，前任姓苏"。得到额外线索：**该律所 2011/2012 首席代表的姓氏**（首席代表比出纳更可能对外公开）。
6. **映射官方名录**：外国律所归司法部管 → 找"外国律所驻华代表机构名单（2012）"，比对哪个所首席代表姓符 → `Ctrl+F` 页面内搜"符" → 唯一命中"符国城"，对应某律所。
7. **两个官方文件闭环**：裁判文书（金额/法院）+ 司法部名单（律所名）打通，答案必然正确。

**要点**：单看裁判文书（律所匿名）或单看司法部名单（不知对应哪案）都无解；**打通**才破案。这就是大数据检索思维。

## 二、大数据检索七步法（可套用）

1. 锁定要证明的**具体事实**和能证明它的**官方来源**。
2. 从**最具辨识度的线索**入手（精确金额、特殊物品、独特地名、案号、IMO）。
3. AI/通用搜索**只找方向**，不作依据。
4. 专业库（北大法宝 `search_case`/`search_article`）一手检索。
5. 命中信息若被匿名/残缺，**深挖脚注、证人证言、附录**找间接标识。
6. 把间接标识**映射到官方名录/登记**（司法部名单、工商登记、法院公告）。
7. 两个以上官方来源**交叉打通**，得出结论并固定证据。

## 三、官网改版绕过（找回被"藏起来"的旧文件）

官网改版后，站内搜索常搜不到旧文件，但文件其实还在服务器上。

- **方法**：`WebSearch` + `site:<官网域名> <标题关键词>` 用外部引擎绕过站内搜索。
- **实战**：司法部 2017 首页改版后，2012 名单站内怎么搜都搜不到；改用 `site:moj.gov.cn 外国律所驻华代表机构 2012` → 第一条就是，URL 路径含"2017 首页改版"字样，证实"改版导致搜不到"的猜测。
- **提醒**：互联网信息每天在变。同样的关键词过一段时间可能又搜不到（服务器清理）——所以**有利信息发现即固定**。

## 四、互联网有记忆：找回被删页面

原始网页删了 ≠ 信息消失。

1. **镜像网站**：法律类内容常被"法律图书馆"等站转载留存；换个站点搜标题关键词。
2. **互联网档案 Wayback Machine**（`web.archive.org`）：保存全球网页历史快照。
   - 用 `WebFetch` 抓 `https://web.archive.org/web/*/<原网址>` 或在其站内搜原网址，取删除前的历史版本。
   - 用途：证明页面被篡改（对比历史版本）、找回被删的有利证据。
3. **去掉限定再搜**：若 `site:` 太窄，去掉 `site:` 直接搜标题，往往有第三方站点收录了副本。

## 五、多维线索定位主体（人 / 公司 / 机构）

- 从最具体的已知 token 起手：姓名、案号、精确金额、时间、地点、车船号、特殊行业术语、奢侈品。
- 在裁判文书中用**独特关键词**搜（如"玛莎拉蒂""4426万"），比用普通词命中率高得多。
- 深挖**脚注 / 证人证言**里的间接标识：代表姓氏、前任姓名、职务变迁、任职年份。
- 把标识**映射到官方名录**（司法部"外国律所驻华代表机构名单"、工商登记、行业协会名册）。
- **防同名同姓**：绝不凭姓名定人，必须用"案号+金额+地点+时间"多维交叉锁定唯一主体（对应主 SKILL 陷阱 09）。

## 六、专业库"搜不到"时的排查清单

北大法宝返回 0 条时，依次尝试：
- [ ] 换关键词：法院层级（中院/高院）、日期范围、案由表述、当事人。
- [ ] 语义检索 vs 关键词检索互换（`search_case` 支持自然语言）。
- [ ] 改用结构化 `get_case_list`（标题+正文关键词组合）。
- [ ] 法条：`search_article` 定位后用 `get_article`（法律全名+中文条号）取正文。
- [ ] 通用搜索 `site:wenshu.court.gov.cn` / `site:court.gov.cn` 补充。
- [ ] 仍无 → 才可记"高度怀疑不存在（失败分级 D）"，并列出**全部已尝试工具**。

> 记住：只有"专业库 + 通用搜索 + 官网 site:"全部无果，才允许下"不存在"的结论。
