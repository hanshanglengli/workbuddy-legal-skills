# 高级检索命令速查

> 在 `WebSearch`（或百度/必应/谷歌）里使用。效果远超裸关键词，尤其当官网自带搜索很弱、或内容因改版被藏起来时是刚需。

## 核心命令

| 命令 | 含义 | 示例 |
|------|------|------|
| `site:域名 关键词` | 限定单一站点（**改版绕过神器**） | `site:moj.gov.cn 外国律所驻华代表机构 2012` |
| `inurl:关键词` | 网址中包含某串 | `inurl:court 执行`、`inurl:gov 公告` |
| `filetype:格式 关键词` | 限定文件格式 | `filetype:pdf 执行裁定书`、`filetype:ppt 普法` |
| `intitle:关键词` | 关键词必须在标题里 | `intitle:执行裁定书` |
| `"精确短语"` | 精确匹配，不拆词不换序 | `"(2022)沪01民终12345号"` |
| `关键词 -排除词` | 减号排除干扰词 | `仲裁 -劳动`（只要商事仲裁，去掉劳动仲裁噪声） |

要点：
- `site:` 与 `inurl:` 功能重叠——`inurl:` 里写完整网址其实就等于在单站点搜。
- 减号 `-` 紧贴排除词，中间不留空格。
- 双引号防止引擎把短语拆散/重排，查案号、精确金额时必用。

## 官网"改版绕过"技巧

官网站内搜不到旧内容（常因改版，如改版前的页面搜不到）时，**不要**下"数据不存在"的结论：
1. 取旧文件的准确标题或公告名。
2. 在 `WebSearch` 里用 `site:<官网域名> <标题关键词>` 检索。
3. 官网搜索框做得差，但外部引擎的索引里往往还留着这个页面。

*实战*：司法部 2017 改版后，2012 外国律所名单站内怎么搜都没有；`site:moj.gov.cn 外国律所驻华代表机构 2012` → 第一条就是，URL 路径含"2017 首页改版"字样。

## 页面内搜索

`Ctrl+F` 在网页和本地文档里都能用，用来在超长的官方 PDF/HTML 里跳到某个姓氏或 token（如在 2012 名单里搜"符"锁定律所）。

## 常用站点限定

| 目标 | 限定写法 |
|------|----------|
| 裁判文书 | `site:wenshu.court.gov.cn "关键词"` |
| 法院公告/开庭/悬赏 | `site:court.gov.cn` / `site:chinacourt.org` |
| 政府/部委官网 | `site:gov.cn` / `site:moj.gov.cn` |
| 全国人大（法条原文） | `site:npc.gov.cn` |

## 工作流提醒
- 先用 AI/通用搜索找线索，再用命令 + 官方来源求证。
- "搜不到" = 换个命令或换个站点，**不是**"不存在"。
- 判例真伪最终以北大法宝等专业库为准，通用搜索只作补充。
