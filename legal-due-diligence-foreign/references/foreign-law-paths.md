# 域外法查明路径（Skill 3 reference）

> agent 用 WebFetch 自由资源查外国法。付费库（Lexis/Westlaw）仅指导。

---

## 数据库选择

| 数据库 | 类型 | 获取 | 说明 |
|--------|------|------|------|
| Lexis / Nexis | 商业核心 | 校内已购 / 国图读者证 | 最重要外文库（仅指导） |
| Westlaw | 商业竞争 | 法学院订阅 | 与 Nexis 二选一 |
| WorldLII | 免费 | 直接访问 | 汇总各国法规案例，按国家查 |
| 商务部 Globlaws | 免费（中文） | 直接访问 | 按大洲/国家分类查境外法规 |
| PACER | 美国法院卷宗 | 按页收费（0.1美元/页，单文件封顶3美元） | 全案可能数十美元 |
| Nexis 免费卷宗系统 | 美国法院卷宗 | Nexis 会员免费 | 数据同 PACER，向 Nexis 代表申请试用 |

## 一带一路小语种法律查明

| 国家 | 路径 | 备注 |
|------|------|------|
| 老挝 | Globlaws → 亚洲 → 老挝 → 国际劳工组织老挝立法 → 民事诉讼法 | 英文版 PDF |
| 马来西亚 | WorldLII → 马来西亚 → 成文法 → 仲裁法 2005 | 必应确认 2018 修订，从亚太国际仲裁中心下载最新版 |
| 吉尔吉斯斯坦 | Globlaws → 亚洲 → 一般法律规定 → 民事典 | 分两部分，共 93 页英文版 |

> 关键：先找数据库（Globlaws/WorldLII）→ 再用检索语法 → 最后必应/官网确认修订版（时效性核验）。

## 域外法检索通用流程

1. 定国家/地区 → 选数据库（Lexis/WorldLII/Globlaws）
2. 用检索语法（通配符 `!` + 间隔 `W/n` + 同句 `W/S`）
3. 看判例效力标识（Lexis 彩色标志）筛有效判例
4. **验证时效性**：必应/官网确认是否有修订版
5. 交叉验证：至少两个独立来源相互印证

## 实证研究选题方向

- "美国法院判决中的中国法"：中国相关词（China, Chinese, PRC）OR 连接 + 法律相关词（law, code, regulation）OR 连接，两组用间隔字数连接
- "外国法院判决中的中国判决"：同理
- 价值：易申报科研项目，抢占学术赛道
