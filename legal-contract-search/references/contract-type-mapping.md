# 合同类型 → 检索映射表（Skill 1 核心 reference）

> 本表是 `legal-contract-search` 技能的执行路由核心。agent 接到合同起草/审查任务后，按本表逐级路由：
> **合同类型 → 判定角色 → 查标的公司池 → 选数据源 → WebFetch 解析 → 交付素材包**。
>
> 标的公司池按"信息披露最规范"原则选取（非用户作业习惯），用户可在调用时指定替换。
>
> 质量分档：
> - **A 档**：巨潮/交易所公告强制全文披露协议，agent 能直接 WebFetch 到真实签署文本
> - **B 档**：公开中文真范本稀少，主要靠 Law Insider 英文 + 官方示范文本 + 微信搜一搜实务文章

## 1. 商场/房屋租赁合同（A 档，已讨论确认）

**子类型**：商铺租赁、写字楼租赁、厂房租赁、住宅租赁
**角色判定（关键，决定搜哪边）**：
- 承租方（品牌方）→ 查零售/餐饮连锁年报"经营租赁"章
- 出租方（业主）→ 查商场运营商招股书/年报"租赁业务"章

**标的公司池**：
- 承租方视角：海底捞、名创优品、瑞幸、九毛九、优衣库（迅销）、星巴克（美股10-K lease commitments）
- 出租方视角：万达商管、华润万象生活、龙湖（天街）、新城控股（吾悦）、大悦城、太古地产、恒隆

**关键词**：`公司名 + (租赁合同 | 租赁协议 | 经营租赁 | 房屋租赁 | 商铺租赁)`
**数据源**：巨潮资讯网年报 → 港交所披露易招股书 → SEC EDGAR（美股品牌10-K）
**条款骨架**：主体 → 租赁物（铺位/面积/楼层）→ 租期 → 租金（固定+营业额抽成"保底+扣点"）→ 保证金 → 装修期/免租期 → 经营管理费 → 营业时间/营业额上报 → 转租权 → 提前解约 → 消防与证照
**兜底**：巨潮无果 → Law Insider（lease agreement）→ 微信搜一搜"商铺租赁合同 核心条款"

---

## 2. 股权投资/增资协议（A 档）

**子类型**：增资扩股、股权转让式投资、可转债投资、PreIPO轮投资
**角色判定**：投资方 / 标的公司 / 原股东——三方协议，搜"对外投资"公告（投资方视角）

**标的公司池（披露规范）**：
- 宁德时代、比亚迪（频繁对外投资，公告多）
- 海康威视、药明康德、迈瑞医疗（各行业龙头对外投资公告）
- 上市公司参与的产业基金增资公告

**关键词**：`公司名 + (增资协议 | 投资协议 | 对外投资 | 签署《 | 增资扩股 | 战略投资)`
**数据源**：巨潮"对外投资暨签署协议"公告（监管强制全文披露协议）→ 港交所/SEC（境外投资）
**条款骨架**：估值与对价 → 股权比例 → 交割先决条件 → 陈述与保证 → 知情权/一票否决 → 反稀释 → 优先清算/优先认购 → 回购权 → 董事席位 → 竞业限制 → 保密与违约
**兜底**：Law Insider（investment agreement / subscription agreement）→ 微信搜一搜"增资协议 核心条款"
**注意**：优先用"对外投资公告"全文，比泛搜"投资合同范本"质量高一个数量级

---

## 3. 股权转让协议（A 档）

**子类型**：协议转让、国有产权转让、要约收购、收购报告书
**角色判定**：转让方 / 受让方 / 标的公司

**标的公司池**：
- 各重大收购案（如产业整合、借壳上市）的收购报告书附协议
- 国有股权转让（北交所/上交所产权披露）
- 上市公司权益变动报告附《股权转让协议》

**关键词**：`公司名 + (股权转让协议 | 股权转让 | 权益变动 | 收购报告书 | 转让标的 | 标的股权)`
**数据源**：巨潮"权益变动报告书/收购报告书"（附全文协议）→ 北交所/上交所信息披露平台（国有产权）
**条款骨架**：标的股权 → 转让价款与支付 → 交割条件 → 过户安排 → 陈述与保证 → 过渡期安排 → 违约责任 → 争议解决
**兜底**：Law Insider（share purchase agreement / SPA）→ 微信搜一搜"股权转让协议 要点"
**注意**：国有股权转让需走产权交易所进场交易程序，范本结构与协议转让不同

---

## 4. 合资经营合同（A 档，中等偏上）

**子类型**：合资公司设立、中外合资、新能源合资、产业合资
**角色判定**：合资各方（通常2-3方）

**标的公司池**：
- 汽车合资（上汽+奥迪、长安+福特类历史公告）
- 新能源合资（宁德时代合资电池项目公告）
- 半导体/芯片合资（中芯国际系）
- 上市公司"共同投资设立合资公司"公告

**关键词**：`公司名 + (合资合同 | 合资协议 | 合资经营 | 共同投资设立 | 合资公司 | 出资比例)`
**数据源**：巨潮"对外投资设立合资公司"公告（常附合资合同核心条款）
**条款骨架**：合资各方 → 注册资本与出资比例 → 出资方式与期限 → 公司治理（董事会/股东会表决）→ 利润分配 → 经营范围 → 退出/转让限制 → 期限与解散 → 违约责任
**兜底**：Law Insider（joint venture agreement）→ 微信搜一搜"合资合同 核心条款"
**注意**：中外合资经营企业法已并入外商投资法（2020），旧范本的"合营期限审批"等条款已失效，需用2020后范本

---

## 5. 劳动合同（B 档）

**子类型**：标准劳动合同、劳务派遣、竞业限制协议、保密协议、高管聘用合同
**角色判定**：用人单位 / 劳动者

**标的公司池（示范文本而非真实签署版）**：
- 人力资源社会保障部劳动合同示范文本（官方，全国通用基础版）
- 各省市人社厅地方版本（北京/上海/深圳/成都等）
- 上市公司股权激励公告中的高管聘用/竞业限制条款

**关键词**：`劳动合同示范文本 | (竞业限制 | 保密协议 | 劳务派遣) 协议 | 高管聘用合同`
**数据源**：人社部官网示范文本 → 各地人社厅 → 巨潮"股权激励/高管聘用"公告 → 微信搜一搜实务文章
**条款骨架**：合同期限（固定/无固定/以完成工作任务）→ 工作内容与地点 → 工作时间与休息 → 劳动报酬 → 社保公积金 → 劳动保护 → 保密与竞业限制 → 合同解除与终止 → 经济补偿 → 争议解决
**兜底**：Law Insider（employment agreement，英文参考）→ 微信搜一搜"劳动合同 风险点"
**质量警示**：
- 劳动法**地方性强**（各地最低工资、社保、裁员规则不同），范本必须结合地方条例
- "真实签署版"罕见，公开的多为官方示范文本或企业自制模板，不能直接当通用模板用
- 竞业限制重点：范围、期限（≤2年）、补偿标准（各地不同，如江苏不低于离职前12个月平均工资1/3）

---

## 6. 借贷/借款协议（A 档）

**子类型**：银行借款、民间借贷、委托贷款、最高额借款、担保借款
**角色判定**：贷款人 / 借款人 / 担保人

**标的公司池**：
- 上市公司"借款/授信/担保"公告（银行借款协议）
- 委托贷款公告
- 民间借贷：最高法司法解释配套的示范条款（实务文章多）

**关键词**：`公司名 + (借款合同 | 借款协议 | 授信 | 委托贷款 | 最高额保证) | 民间借贷 + (利率 | 担保)`
**数据源**：巨潮"借款/担保"公告 → 微信搜一搜"民间借贷合同 核心条款"（结合最高法2020司法解释）
**条款骨架**：借款金额 → 借款用途 → 借款期限 → 利率与计息（民间借贷≤LPR四倍）→ 还款方式 → 担保（保证/抵押/质押）→ 违约责任 → 提前到期 → 争议解决
**兜底**：Law Insider（loan agreement）→ 微信搜一搜
**注意**：
- 民间借贷利率上限 = LPR四倍（2020年8月后规则，取代旧的24%/36%）
- 担保部分单独看《民法典》担保制度司法解释，保证方式约定不明推定为一般保证（2021后规则变化）

---

## 7. 买卖合同（B 档）

**子类型**：货物买卖、大宗商品、设备采购、分期付款买卖
**角色判定**：买方 / 卖方

**标的公司池**：
- 上市公司"重大采购/销售合同"公告（偶有，质量高但稀疏）
- 贸易类/制造类公司年报关联交易披露
- 大宗商品贸易商（如厦门象屿、物产中大）的采购销售公告

**关键词**：`公司名 + (买卖合同 | 采购合同 | 销售合同 | 重大合同 | 供货协议 | 采购框架协议)`
**数据源**：巨潮"重大合同"公告 → Law Insider（sale and purchase agreement, SPA / supply agreement）→ 微信搜一搜
**条款骨架**：标的物（名称/规格/数量）→ 价款与支付 → 交付与验收 → 风险转移与所有权保留 → 质量与瑕疵担保 → 违约责任（迟延/不合格）→ 解除权 → 不可抗力 → 争议解决
**兜底**：Law Insider 英文为主 → 微信搜一搜"买卖合同 风险点"
**质量警示**：公开中文"真范本"稀少，巨潮偶发；日常买卖多靠《民法典》合同编通则 + 行业惯例自拟，agent 应提示用户以 Law Insider 英文结构为骨架

---

## 8. 服务/承揽合同（B 档）

**子类型**：服务合同、承揽（加工/定制）、咨询合同、外包合同、技术服务合同
**角色判定**：委托方 / 受托方（承揽人）

**标的公司池**：
- 上市公司"重大服务合同"公告（稀疏）
- IT/外包类公告（如银行IT外包采购）
- 技术服务合同：可参考技术合同认定登记的示范文本

**关键词**：`公司名 + (服务合同 | 承揽合同 | 委托合同 | 外包协议 | 咨询协议 | 技术服务合同)`
**数据源**：巨潮"重大合同"公告 → Law Insider（services agreement / consultancy agreement）→ 微信搜一搜
**条款骨架**：服务内容与范围 → 服务期限 → 服务费用与支付 → 验收标准 → 知识产权归属 → 保密 → 转包限制 → 违约责任 → 解除 → 争议解决
**兜底**：Law Insider 英文为主 → 微信搜一搜"服务合同 风险点"
**质量警示**：与买卖合同同档，公开真范本稀；承揽合同注意"定作人随时解除权"（《民法典》第787条）这一特殊条款

## 通用执行规则（适用于全部 8 类）

1. **先判角色再选标的池**：同一合同类型，代表哪一方决定搜哪家公司（如租赁的出租/承租）
2. **优先巨潮公告全文**：监管强制披露的协议 > 泛搜范本，质量差一个数量级
3. **结果中检索缩小**：先广搜 `公司名 + 合同类型`，再在结果里用具体条款词（如"免租期""反稀释""利率上限"）锁定段落
4. **首尾呼应**：搜到范本后，用企业名反查 pkulaw 该企业纠纷裁判文书，看法官怎么评价这类条款，反推改进
5. **兜底链**：巨潮无果 → Law Insider（英文结构骨架）→ 微信搜一搜（实务文章补充中文要点）
6. **来源标注（强制）**：交付时写清"来源：X公司Y年Z场景的合同/官方示范文本/Law Insider英文范本"，禁止当通用模板直接套用
7. **时效校验**：引用 2020 年前范本须核对法律变动（如外商投资法2020、民法典2021、民间借贷利率2020.8）
