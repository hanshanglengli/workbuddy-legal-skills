# legal-contract-search（合同起草检索 · agent 执行型）

## 定位

接到"起草/审查某类合同"任务时，**agent 主动调工具搜**真实合同范本、相关法规、裁判文书中的条款原文，交付可参考的合同素材包。不是教人怎么搜，而是 agent 直接搜。

## 与其他技能的分工

- 本技能管"合同怎么搜、搜什么公司"（执行）
- `legal-research` 管"搜到的对不对"（防幻觉、四核对、交叉验证）——本技能交付结果后，可交给它核验
- 北大法宝高阶语法/案例效力位阶见 `legal-pkulaw-search` 的 references（pkulaw-syntax.md / case-hierarchy.md）

## 触发条件

用户提到合同起草、合同范本、审查要点、合同条款，或具体合同类型（租赁/投资/增资/股权转让/合资/劳动/借款/买卖/服务/承揽），或具体条款（留置权/不可抗力/竞业限制/反稀释等）。

## 核心执行流程（四步法 = agent 工作流）

讲座的"合同起草四步法"降级为 agent 内置规划逻辑，不作为教程正文：

### 步骤 1 · 范本检索（WebFetch + 映射表）
1. 识别合同类型 → 查 `references/contract-type-mapping.md` 路由表
2. 判定用户代表哪一方（出租/承租、投资方/标的、买方/卖方）→ 选对应标的公司池
3. WebFetch 巨潮资讯网：`公司名 + 合同类型关键词`，定位年报/公告中的合同正文段落
4. 境外主体：WebFetch SEC EDGAR（美股10-K/20-F lease commitments）/ 港交所披露易（招股书）
5. 中文真范本稀时：WebFetch Law Insider（英文结构骨架）

### 步骤 2 · 规范检索（pkulaw MCP）
- 调 pkulaw 法规/司法解释检索，缩小到该合同类型的相关规范
- 如借贷→民间借贷利率上限（LPR四倍）、担保制度司法解释；劳动→劳动合同法 + 地方条例

### 步骤 3 · 要点检索（WebFetch 微信搜一搜/搜狗微信）
- 两个渠道算法不同，交替使用：`合同类型 + 实务要点/风险点/审查要点`
- 提取审查清单（如租赁的"免租期/抽成/转租权"，投资的"反稀释/回购/一票否决"）

### 步骤 4 · 裁判规则检索（pkulaw MCP + 企业名反查，首尾呼应）
- 用步骤1的企业名反查 pkulaw 案例库，搜该企业/该合同类型的纠纷裁判文书
- 从裁判文书中提取法官引用的**合同条款原文**（讲座留置权实战逻辑）
- pkulaw 间隔字数语法：`第~10约定 约定~200留置` 突破高级检索99字限制（见 `legal-pkulaw-search` 的 pkulaw-syntax.md）

## 交付物（合同素材包）

每次执行后交付：
1. **范本**：1-3 份真实合同文本片段（标注来源公司、年份、场景）
2. **规范清单**：相关法规/司法解释条文
3. **审查要点**：实务风险点清单
4. **条款原文**：从裁判文书提取的、经诉讼检验的条款原文（如有）
5. **来源标注**（强制）：每条素材写明出处，禁止当通用模板直接套用

## 环境适配（agent 能力边界）

| 动作 | 工具 | 可执行 |
|------|------|--------|
| 巨潮/SEC/港交所/Law Insider 检索 | WebFetch | ✅ |
| 中国法规/案例检索 | pkulaw MCP | ✅（已连接） |
| 微信搜一搜/搜狗微信 | WebFetch | ✅ |
| 香港查册中心调档 | WebFetch | ⚠️ 部分（需付费调档） |
| Lexis/Nexis/Westlaw 付费库 | 无 MCP | ❌ 仅附注语法 |
